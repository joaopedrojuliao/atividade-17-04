# Exercícios de Lógica e Manipulação de Dados em Python

Este repositório contém uma série de exercícios práticos desenvolvidos em Python (Jupyter Notebook) com foco em estruturas de repetição, condicionais avançadas e tratamento de dados simples.

## 📋 Sobre o Projeto

O objetivo deste projeto é demonstrar a aplicação de conceitos fundamentais de programação para resolver problemas comuns de negócios, como gestão de estoque, cálculo de descontos progressivos e sistemas de segurança/autenticação.

## 🛠️ Exercícios Incluídos

O arquivo `Atividade 17:04.ipynb` aborda os seguintes cenários:

1.  **Validador de Estoque**: Sistema que emite alertas de reposição baseados em quantidade e preço unitário, com validação de entradas nulas.
2.  **Simulador de Descontos**: Lógica de precificação dinâmica baseada no faturamento total e região geográfica do cliente.
3.  **Sistema de Login**: Implementação de controle de acesso com limite de tentativas e bloqueio de conta.
4.  **Filtro de Vendedores de Elite**: Processamento de listas para extração de médias financeiras, ignorando usuários administrativos ou de teste.

## 🚀 Tecnologias Utilizadas

* **Python 3.x**
* **Google Colab / Jupyter Notebook**
